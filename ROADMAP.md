# DocuMind — дорожная карта проекта

RAG-сервис «задай вопрос своей документации»: загрузка документов, асинхронная
индексация через Kafka, гибридный поиск (pgvector + полнотекстовый) и ответы LLM
с цитатами-источниками.

Порядок этапов не случаен: каждый следующий опирается на предыдущий, а проект
в любой момент остаётся в деплоепригодном состоянии.

## M0. Скелет ✅

Каркас репозитория и окружение разработки.

- [x] uv-проект, ruff + mypy + pre-commit
- [x] Docker Compose: PostgreSQL 17 + pgvector, Redis
- [x] CI на GitHub Actions (lint → типы → тесты)

**Готово, когда:** `docker compose up` поднимает стек, CI зелёный с первого коммита.

## M1. Пользователи и документы 🔄

Модель данных и первое API.

- [x] Модели `users` / `documents`, машина статусов документа
- [x] Alembic: миграции с обратимым downgrade
- [x] `core/config.py` на pydantic-settings
- [x] Фабрика асинхронных сессий `get_db` (async engine, `expire_on_commit=False`)
- [x] Pydantic-схемы Create/Read с перекрёстной валидацией
- [ ] JWT-аутентификация (bcrypt + PyJWT, `get_current_user`)
- [ ] Эндпоинты `/auth/register`, `/auth/login`
- [ ] CRUD `/documents`: загрузка файла или URL, список, удаление

**Готово, когда:** регистрация → логин → Authorize в Swagger → загрузка документа
работают одной цепочкой.

## M2. Индексация документов

Конвейер «документ → чанки с векторами» (пока синхронно, через фоновые задачи).

- [ ] Парсер PDF/Markdown/HTML
- [ ] Чанкер с сохранением пути по заголовкам (`heading_path`)
- [ ] Эмбеддинги OpenAI (обёртка за интерфейсом, для тестов — фейк)
- [ ] Расширение `vector` в миграции, колонка `embedding`, индекс HNSW

**Готово, когда:** загруженный документ доходит до статуса `ready`, в базе чанки с векторами.

## M3. Kafka-пайплайн

Вынос индексации в отдельного воркера.

- [ ] Продюсер события `documents.ingestion.requested`
- [ ] Воркер-консюмер: manual commit, ретраи, идемпотентность
- [ ] DLQ для «ядовитых» сообщений

**Готово, когда:** убийство воркера посреди обработки не ломает и не дублирует документ.

## M4. RAG-чат

То, ради чего всё затевалось.

- [ ] Гибридный поиск: pgvector + полнотекстовый, слияние RRF
- [ ] Промпт с нумерованными источниками
- [ ] Стриминг ответа через SSE
- [ ] Сохранение сообщений и цитат (message ↔ chunk)

**Готово, когда:** вопрос в Swagger → поток ответа со сносками на конкретные куски документа.
